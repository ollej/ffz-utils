# Firefly Zero Utilities

A library with utilities to write games in Rust for the [Firefly Zero](https://fireflyzero.com)
handheld retro gaming console.

## Available modules

### Animation

Setup sprite animation with multiple frames of an animation in the same image.

### Audio

Utilities to simplify playing sound effects.

### Bar

A UI bar to draw health bars.

### Camera

A camera that can be used to translate coordinates from camera to world.

### ImageText

Render text from a texture.

### Movable

A trait that can be implemented for entities that can move.

### Particles

A particle system that can display pixel or sprite particles.

### PointMath

A trait with helpful math functions for Point.

### Rectangle

A struct that contains the geometry of a rectangle.

### RisingText

Render texts that automatically moves upwards and disappears after a while.

### TextBox

Render text on screen inside a box, with horizontal and vertical alignment.

### Tile

A tile from a spritesheet.

### TileMap

A struct that can draw tiles from a spritesheet.

### Utilities

Small utilities that don't fit anywhere else.

### Vec2

A 2D vector struct with f32 values.

### Vector

A 2D f32 vector with some angle calculation methods.
